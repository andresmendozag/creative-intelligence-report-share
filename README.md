# Creative Intelligence — Report Share

Static HTML reports published via GitHub Pages.

**Live URL:** https://andresmendozag.github.io/creative-intelligence-report-share/

## How to update

1. Replace the HTML file(s) locally.
2. Commit and push:
   ```
   git add . && git commit -m "Update reports" && git push
   ```
3. Wait ~1 min for GitHub Pages to redeploy. The URL stays the same.
